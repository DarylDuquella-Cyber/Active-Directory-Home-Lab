# Active Directory Home Lab

## Overview
This home lab documents my practice with Windows Server,
Active Directory, and common IT support tasks.

My goal is to build practical skills in managing users,
computers, permissions, and network services.

## Technologies
- Oracle VirtualBox
- Windows Server
- Windows clients
- Active Directory Domain Services
- DNS and DHCP
- Group Policy

## Lab Documentation
I am organizing this repository to cover:

- Lab setup and network configuration
- User and group management
- Joining Windows computers to a domain
- Shared folders and access permissions
- Group Policy configuration
- Troubleshooting steps and results

Documentation in progress. Screenshots and walkthroughs
